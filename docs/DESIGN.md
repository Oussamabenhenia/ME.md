# Design notes

The page is a railway line. A route diagram runs through the masthead, each section header is a station on that
line, and each project plate carries a drawing from its own world. Everything is generated by
`scripts/build_assets.py` (stdlib only): `python scripts/build_assets.py`.

## System

| Item | Rule |
|---|---|
| Canvas | 1000 units wide for every asset, margins 50, one 16px gutter (from Markdown) |
| Plates (opaque) | masthead, R3T (ink), PHYTO (kraft), line follower (cobalt blueprint), Neural Agent (paper + lavender) |
| Sections (transparent) | headers, index, stats, footer. Light and dark variants, switched with `#gh-light-mode-only` / `#gh-dark-mode-only`, so they sit on the page instead of leaving blocks and black gaps |
| Type | serif for voice, Swiss sans for engineering wordmarks, mono for metadata. Smallest text is 20 units |
| Texture | speckle pattern, halftone dots, hairline frame with corner ticks. No filters, glow or gradients |
| Motion | CSS in SVG, slow, off under `prefers-reduced-motion`. Every asset is complete without animation |

## Problems found in the previous version, and fixes

| Problem | Fix |
|---|---|
| Cream blocks separated by near-black bands in dark mode | Sections are transparent with light/dark variants; only plates are opaque |
| Headers were mostly empty cream | Header is a rail + station + numeral + title, content-sized (220 units) |
| Metadata tiny on phones (1200 canvas, 14-16 units) | 1000 canvas, minimum 20 units |
| Flat illustrations | R3T: transit-map geometry plus a time-distance chart. PHYTO: coffee branch with cherries and a cappuccino. Robot: labelled top view, wheel-track dimension, PID feedback loop |
| Product "badge" looked unfinished and read as a logo | Removed. The plate uses generic botanical art, not a brand mark |
| `<details>` marker sat alone above each plate | Plates always visible; notes toggle sits below each plate |
| Grain `filter` could render black in some renderers | Replaced by a plain SVG pattern |
| Content hidden unless animations ran | Everything visible by default; animation only adds motion |
| Small text failed contrast (vermilion on kraft 2.95:1) | Text-safe vermilions (4.24 to 5.55 on their plates) |

## Known limits

- WebKit/Safari not tested here (not installed). `offset-path` has a static fallback.
- Fonts are system stacks, so letterforms differ per OS; display lines are width-locked with `textLength`.
- The light/dark switch works on github.com; other Markdown viewers may show both variants.
- On a phone the small mono metadata is ~7px. Titles and project names stay legible; the same facts are in the alt text and notes.
